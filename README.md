# Дневник

Личное приложение для айфона: дневник, дедлайны, погода на 4 дня,
курсы валют, нефть и золото, тех-новости. В будущем — расписание из
личного кабинета.

## Как устроено

```
GitHub Actions (раз в час)
  └─ scripts/fetch_data.py: курсы ЦБ, Brent и золото, RSS тех-новостей
       └─ data.json выкладывается на GitHub Pages вместе с приложением
                                   │
Айфон: приложение (app/) ◄─────────┘ подтягивает data.json при открытии
  └─ записи и дедлайны — только в памяти телефона (IndexedDB)
```

Погода грузится прямо с телефона из Open-Meteo, город меняется в настройках.

Записи дневника **никуда не отправляются**. Код и `data.json` лежат
в открытом доступе (бесплатный GitHub Pages работает только с публичными
репозиториями), поэтому в `data.json` не должно попадать ничего личного.

## Первый запуск

1. Settings → Pages → Build and deployment → Source: **GitHub Actions**.
2. Actions → «Обновить данные и выложить» → Run workflow.
3. Открыть `https://<логин>.github.io/diary/` в **Safari** на айфоне →
   «Поделиться» → «На экран „Домой“».

Третий шаг важен: без него Safari может стереть данные сайта, который
не открывали несколько недель. С главного экрана — не стирает.

Резервная копия: Настройки → «Сохранить копию» → «Сохранить в Файлы».

## Если что-то сломалось

- Карточка показывает «не обновлялось N ч назад» — источник упал, видны
  последние удачные данные. Причина — в логе последнего запуска в Actions.
- GitHub отключает расписание в публичном репозитории после 60 дней без
  коммитов и присылает письмо. Включить обратно: Actions → workflow →
  Enable workflow.

## Разработка

```bash
python3 -m unittest discover -s tests -t .
python3 scripts/fetch_data.py --out app/data.json   # живые данные локально
python3 -m http.server -d app 8000
```

Без зависимостей: только стандартная библиотека Python и чистый JS.
Источники новостей и котировок — списки в начале `scripts/fetch_data.py`.
